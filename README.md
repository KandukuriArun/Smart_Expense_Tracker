
# 💰 Smart Expense Tracker

Smart Expense Tracker is a simple web application that helps users track their daily income and expenses. It allows users to manage finances efficiently and understand their spending habits.

---

## ✨ Features
- Add income and expense details
- Categorize expenses (Food, Travel, Shopping, Bills, etc.)
- View total income, total expenses, and balance
- Delete expense records
- Data stored using browser Local Storage
- Simple and responsive user interface

---

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Local Storage
